# macOS Barcode Scanner

This application is used to scan different types of known and famous barcodes, focus of support is product barcodes such as EU or US barcodes, and shipping label barcodes which includes both number and text. Follow the rules below for development;

1. No testing, we don't do code testing in this repo, we test functionally via users instead.
2. Do not create complexity for no reason, think simple and prefer simplicity when possible, but don't hate complexity sometimes it could be really needed in those cases its fine otherwise always think simple and prefer simplicity first.
3. Never assume or guess on something, ask if needed or find/search yourself for the answer. Either on web or inside repo.
4. Never create duplicate code, build generic functions when needed and reuse existing logic when possible or modify existing logic to make it generic for multiple consumers.
5. Do not add useless comments that won't help either humans or agents, provide important and useful details on comments, do not explain how code works when we can easily understand it by reading the code.
6. Commit often for easier revert/reset as well as testing BUGs via git bisect or git checkout etc. follow the commit rules/template below.

For every commit use this example reference template: `type(module): title of commit as short as possible` and then you can add a body using bullet list about changes. On each commit add the following line at the very bottom of commit body text:

`Co-Authored-By: ExWeiv BOT via <agent-name> <git-bot@exweiv.com>`

Human commits wouldn't include this so this way you can understand which commits are generated by agents easily, only change the agent-name with your name without thinking level.
